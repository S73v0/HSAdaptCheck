# Local commissioning — development prototype

Record Eclipse/ARIA/ESAPI versions, .NET version, checker commit/version, configuration hash/version, machine model/identifier, test dataset identifiers, physicist, date and independent reviewer. Use approved nonclinical copies. Establish expected results independently of HSAdapt generation and this checker's own extraction. Preserve evidence and obtain clinical approval before clinical use. Separate dosimetric/delivery QA is still required.

- [ ] Build against installed licensed API references and .NET Framework 4.8. Verify read-only script approval/deployment and the script DLL loads.
- [ ] Compare every extracted field with installed API documentation and Eclipse displays/independent records, including Gy vs cGy, mm and DICOM frames. Confirm no patient modifications or save operations occur.
- [ ] Select intended reference/adaptive datasets and independent expected UIDs. Test wrong plan with a plausible ADP name, wrong course, wrong CBCT, wrong structure set and wrong frame UID. Expect FAIL on affected comparisons. Selecting the same plan twice must FAIL.
- [ ] Test absent/null expected identifiers, unconfirmed configuration, missing configuration version/source, absent getters and extraction exceptions. Affected rows must be NOT VERIFIED, never PASS.
- [ ] Remove a required target, empty it, introduce case-variant duplicate IDs or alias overlap, remove an OAR and omit mappings. Expect FAIL for absent/empty/ambiguous configured requirements and NOT VERIFIED for omitted mapping requirements. Non-empty anatomically wrong contour may pass existence: document that this requires clinical review.
- [ ] Change adaptive fractions/dose independently from the original course. Check both mismatch cases and correct segment-vs-course comparison. Test multi-level prostate/nodal prescription: target dose levels remain NOT VERIFIED; do not approve them from a global Rx match.
- [ ] Remove dose, change algorithm/grid and simulate unsupported settings/member access. Expect FAIL for absent dose or known mismatches; unsupported/missing evidence must be NOT VERIFIED. Dose currency must always be NOT VERIFIED, even after calculation; edit the plan after capture and demonstrate the old report remains only a snapshot.
- [ ] Change machine, energy, beam count, MU, isocentre, beam IDs; add/remove beams and introduce duplicate expectations. Confirm FAIL/NOT VERIFIED as appropriate. Check setup beams excluded and collection failures do not produce complete-count PASS.
- [ ] Independently establish tolerance-boundary cases, negative/missing/non-finite tolerances/data and coordinate units/signs. Verify per-axis position comparison, not radial distance. Validate dose-grid lattice semantics locally.
- [ ] Confirm reference/adaptive beam summaries and deltas include intended changes. Rationale must leave change rows REVIEW and cannot override adaptive discrepancy failures. Different frames must not be interpreted as physical isocentre displacement.
- [ ] Load malformed configuration, deny file access, fail extraction/export and change selections after capture. Verify visible failure, invalidation and no stale active report. Review local configuration schema and prevent accidental misspelling/duplicate JSON keys operationally.
- [ ] Export HTML and inspect all labels, expected/observed values, sources, capture time, versions, identifiers and hashes. Compare exported values independently; exercise report escaping and approved storage controls. Rerun after any edits.
- [ ] Document not-tested features and failure modes. Independently review source and synthetic tests; compare with deliberate local error cases. Complete site risk assessment and formal clinical approval. Do not treat a successful build or synthetic test suite as clinical validation.
